# 日历专注记录

2026-11-18。保持原有日程弹窗、番茄详情和编辑入口，新增以下能力：

- 左侧“番茄”标题行切换卡片和竖轴。缺少配置时默认竖轴，已明确保存的卡片选择继续保留。
- 主日历及右侧单日栏共用时间映射和竖轴绘制。记录为 6px 宽，贴近右边线；与日程保留 4px 可见间隙，占位及选择预览使用相同间隙。
- 竖轴悬停在记录左侧或右侧显示原详情，按窗口可用空间选边，点击固定。关联高亮按同一显示日期和任务 ID 匹配。
- 竖轴详情与日程弹窗共用宿主可见边界，窄侧栏自动收窄，较矮窗口限制弹窗高度并允许内部滚动；窗口及主题缩放后仍留在可见区域内，不越出侧栏宽度。
- 悬浮、键盘聚焦或选中有关联任务的日程时，反向描边当天同一任务的专注和正计时记录，不要求时间重叠。悬浮优先于选中，移开后恢复选中高亮；取消选择后清除。两种样式、主日历及两个右侧单日入口共用匹配逻辑，不读取额外历史。
- 新建日程占位及选择预览与普通日程一样为竖轴预留空间。
- 非番茄的已保存定时日程在头部时长行右侧提供“转专注记录”。全天日程、任务日期和新建草稿不显示该入口。
- “补录专注”及“撤销记录修改”位于番茄筛选下方。
- 正在运行的计时会显示尚未保存的色段，复用 `__tomatoTimerV2.getState()` 的当前 segmentStartMs 与任务关联，从本次开始或继续的时刻画到当前时间，不包含暂停间隙，不写入历史。详情标记“计时中”，保存前不能编辑。专注、休息、正计时和总显示开关继续生效。

实时色段和当前时间指示器共用已有的分钟刷新，不新增秒级轮询。竖轴增长时直接更新原节点的几何和文案，保留日程、滚动位置及编辑草稿，不读取历史；开始、结束或显示结构变化时才走现有重绘路径。页面隐藏后停止显示更新，回到前台立即补齐。月视图只在打开单日栏后启动同一分钟节奏。旧版番茄插件没有 V2 状态接口时仍显示已保存记录。

## 配置与组件边界

`calendarTomatoDisplayMode: 'card' | 'rail'` 是唯一的显示配置，已接入默认值、本地持久化、共享配置加载、导入导出和渲染缓存键。

两种样式共用记录和详情；切换只重绘当前事件，不重新读取历史。只有 rail 分支将番茄记录从日程的重叠布局中移出。清单右侧日历通过自己的辅助事件源读取同一番茄历史；月视图隐藏记录卡片时仍保留单日栏所需事件，月格、周格、全天区和列表继续原有显示。

记录编辑复用现有 `openRecordModal`。新增与转换使用同一个表单和保存路径，编辑、拖动与调整大小共用时间更新路径。转换读取当前未保存的日程时间及关联任务，保留原日程；取消返回原编辑草稿。没有额外确认复选框或偏差指标。

时间输入显示到分钟，未修改的端点保存原有秒数及毫秒。编辑、拖动、拉伸都以本次调整的记录时段为准，自动缩短与其重叠的其他记录，中间重叠时拆分，完全覆盖时从显示中移除；一次撤销同时恢复本条和受影响的其他记录。普通补录仍检查重叠。保存失败会区分时间无效、正在计时、记录过期和写入失败，保留当前编辑内容。

## Dock Tomato 接口

在现有 `globalThis.__dockTomato.history` 上增加：

- `create({start, end, mode, taskBlockId, taskBlockName, source, sourceScheduleId})` 返回 `{ok, records, undo}` 或 `{ok:false, error}`。`source:'schedule'` 用完整新时段覆盖重叠历史：边缘重叠缩短旧记录，中间重叠拆为两段，完全覆盖保留不显示的 tombstone，防止计时日志重新引入旧时段。未覆盖的旧片段保留关联、来源等信息；第一片段沿用 recordId，第二片段分配新 ID。普通补录仍拒绝重叠。
- `update(recordKey, {start, end})` 保留 recordId，返回同样的回执，复用日程转专注的区间截断逻辑。编辑与所有受影响记录在同一次历史写入中提交，包含跨年调整。按原起止时间检查过期编辑，时间比较兼容不同日期格式。撤销回执包含本条及其他受影响记录，保留原历史重叠的恢复能力。
- `undo(receipt)` 仅撤销本次回执涉及的记录，遇到后续修改或恢复时间冲突时返回 false。

写入沿用番茄插件的串行队列、年分片、版本检查和刷新流程。覆盖涉及的截断、拆分、删除标记和新增在同一次写入中完成，撤销同时恢复它们；期间任何一段发生后续变化会阻止撤销。保存时重新读取占用，预览显示完整时长与受影响记录条数，不作为写入依据。当前运行及尚未提交的计时段禁止覆盖。

新增记录标为手动来源，日程转入另存 entrySource 和 sourceScheduleId；不调用计时器完成事件。未来时间和无效区间被拒绝；同一日程、任务、类型、起止时段未变时重复转入不增加记录。撤销只保留当前会话最后一次成功修改。

旧版番茄插件仍可显示记录和使用已有时间编辑；创建接口缺失时提示更新。日程转换还要求 `history.supportsScheduleOverwrite === true`，避免旧版 create 接口静默跳过已有时段。使用本次转换能力需要同时更新两个插件。

## 验证

`scripts/calendar-focus-records-browser.test.js` 使用生产日历代码和真实记录服务，在隔离存储中验证切换、几何、悬停固定、原生编辑、转换草稿、补录、撤销和窄屏。番茄侧的 `scripts/history-manual-records.test.js` 验证区间扣除、并发去重、稳定 ID、运行时占用、跨年和撤销冲突。以上测试不写用户笔记或真实番茄历史。

`scripts/calendar-tomato-rail-hosts-browser.test.js` 从生产事件源加载记录，实际挂载独立清单侧栏及月视图单日栏，验证默认竖轴、历史延迟加载后的绘制、记录更新订阅、占位及选择预览避让、左右弹窗定位与侧栏销毁清理。

`scripts/calendar-tomato-relations-browser.test.js` 验证主日历、清单侧栏及月视图单日栏的双向高亮、同日及任务匹配、悬浮与选中优先级、取消清理、重新绘制和卡片模式。

`scripts/calendar-live-tomato-browser.test.js` 用受控时钟验证三个入口的未保存色段、按分钟增长、保留 DOM、不重读历史、详情与关联、暂停继续、已保存记录去重、显示筛选、前台恢复、倒计时结束边界及跨天裁切。
