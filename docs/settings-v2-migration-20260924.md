- 11 个分类：文档与来源、任务行为、常规与入口、视图与布局、外观与显示、日历与提醒、专注与联动、AI 助手、筛选与排序、功能权益、数据与维护。
- 新增 `main/settings/68-settings-v2.js` 并接入主 manifest。复用生产设置渲染器及其真实数据、校验、权限和事件，按分类重新组织已有控件。
- 使用内部 BASECOAT 的按钮、文本输入和分区导航样式；默认视图、点击行为、位置、密度、日历模式、AI 模式等固定短选项改为原型式分段按钮组，复用 `bc-tabs-list` / `bc-tabs-trigger`，以单选组语义提供方向键和 Home/End 操作。文档、笔记本、规则字段和较长时间刻度继续使用选择器，开关使用 `b3-switch`。主题变量局限于设置容器，避免继承任务顶栏的白色文字。
- 主设置页取消保存、取消和未保存状态；普通设置沿用原写入链路，规则、优先级、四象限、安排策略、定时事件改为有效修改自动写入。文本输入短暂防抖，切换和关闭时补齐输入。
- 自动写入按领域串行，合并同一对象的连续修改。失败显示错误和重试入口；策略版本冲突重新读取，禁止重试过期快照。新定时事件默认暂停，编辑保留调度器生成的运行记录。
- 搜索按实际渲染内容建立索引，跨分类定位设置、展开折叠内容并聚焦控件；移动端也保留搜索。
- 保留焦点与同页滚动，切换分类从顶部开始；支持窄屏、明暗主题、键盘搜索、焦点循环和 Escape 关闭。

创建数据对象、自定义字段定义/属性键迁移、导入、删除、清空等工具继续沿用其校验和显式执行步骤。这些操作不由主设置页的自动写入队列自动触发。

## 数据导入顺序与扫描设置核查

- “文档与来源”的正文及分区导航现在按“文档分组与管理 → 扫描范围 → 数据导入”排列；页签自定义分组仍位于文档管理区域。导入面板使用明确的 `import` 分区标识，移动原有控件，不复制导入入口。
- 递归文档数上限仍有效，默认 2000。当前加载器先调用 `resolveDocIdsFromGroups`，其来源展开走 `__tmExpandSourceEntryDocIds`，笔记本和包含子文档的来源都读取 `recursiveDocLimit` 并限制文档数量；随后才调用 `API.getTasksByDocuments(allDocIds, ...)`。因此，范围内的全量任务加载不代表忽略文档来源及其展开上限。
- 父任务回溯层数仍由 `__tmResolveDocTaskParentLinks` 读取，用于跨普通列表等中间块寻找父任务，不限制扫描数量。设为 0 只关闭额外回溯，直接父子关系仍会解析。
- 两项设置均保留，说明分别明确文档数量上限和层级识别的作用；此次未改变扫描算法或已有设置值。
- 浏览器回归通过正文紧邻顺序、页签顺序、导入分区跳转和 200 行设置覆盖；子文档查询、文档加载顺序、设置接线 3 个既有合约及完整 manifest 语法检查通过。
- 本轮修改前安装包备份：`.codex-tmp/settings-v2-before-import-order.zip`。
