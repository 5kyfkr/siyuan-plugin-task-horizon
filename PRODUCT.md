# Product

## Register

product

## Users

Task Horizon serves SiYuan users who manage tasks across documents, lists, calendars, boards, and review views. Users may be experienced task-system builders or newcomers who need familiar controls and clear outcomes without learning implementation terms.

## Product Purpose

The plugin brings distributed SiYuan tasks into one operational workspace for capture, planning, execution, querying, and review. Its Agent integration should combine SiYuan's document understanding with Task Horizon's structured task and schedule capabilities while keeping every write understandable and controllable.

## Brand Personality

Calm, clear, and familiar. The interface should feel like a focused extension of SiYuan, with the restraint and directness associated with tools such as Notion.

## Anti-references

Avoid marketing-style layouts, decorative card collections, oversized typography, gradients, glass effects, unfamiliar controls, and explanatory clutter. Do not create a separate visual language that competes with SiYuan's native components or theme.

## Design Principles

- Put the current task and user intent before product decoration.
- Reuse native SiYuan interaction patterns and theme variables whenever possible.
- Keep common actions direct, with advanced detail available progressively.
- Make write scope, consequences, confirmation, and results explicit.
- Preserve compact information density without crowding or hidden behavior.

## Accessibility & Inclusion

Expanded accessibility work is deferred for the current development phase. New changes should preserve existing keyboard and mobile behavior and should not knowingly remove established native affordances.
